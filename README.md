# Chart Studio

График в стиле TradingView для записи роликов с телефона или компьютера: свечи, таймфреймы, движение к заданной цене за заданное число свечей, позиция с живым PnL, тейк-профит и ликвидация.

Обычный статический сайт — HTML, CSS и один файл JS. Без сборки, без зависимостей, без сервера.

---

## Деплой на Vercel через GitHub

1. Создай на GitHub пустой репозиторий, например `chart-studio`.
2. Распакуй архив и залей **содержимое** папки в репозиторий:

   ```bash
   cd chart-studio
   git init
   git add .
   git commit -m "Chart Studio"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/chart-studio.git
   git push -u origin main
   ```

   Либо перетащи файлы в веб-интерфейсе GitHub: **Add file → Upload files**.

3. Зайди на [vercel.com/new](https://vercel.com/new), выбери **Import Git Repository** и укажи этот репозиторий.
4. Framework Preset — **Other**, поля Build Command и Output Directory не заполняй.
5. Нажми **Deploy**. Через минуту получишь ссылку вида `chart-studio.vercel.app`.

Дальше каждый `git push` в `main` обновляет сайт сам.

**Важно:** `index.html` должен лежать в корне репозитория, а не внутри вложенной папки.

## Запись с телефона

### Сначала поставь сайт на домашний экран

Иначе в кадр попадёт адресная строка браузера.

- **iPhone:** открой ссылку в Safari → «Поделиться» → **На экран «Домой»**.
- **Android:** открой в Chrome → меню (⋮) → **Установить приложение**.

Запускай с иконки — сайт откроется на весь экран, без интерфейса браузера.

### Порядок съёмки

1. Кнопка **☰** справа сверху открывает настройки. Задай тикер, диапазон цен, таймфрейм и скорость.
2. Задай цель: цену и за сколько свечей до неё дойти. Галочку «Показывать линию цели» лучше снять, иначе на видео будет видно, куда пойдёт цена.
3. Включи **Чистый режим** — служебные кнопки исчезнут, останутся только Long и Short.
4. Закрой настройки («Готово» или свайп вниз по шапке).
5. Запусти запись экрана и нажми **▶**. Если включён отсчёт, будет 3 · 2 · 1 — успеешь убрать палец.
6. В чистом режиме график запускается и ставится на паузу **касанием по графику** — кнопка ▶ в кадр не попадает.

### Жесты

| Жест | Действие |
|---|---|
| Протянуть пальцем | прокрутка графика |
| Щипок двумя пальцами | масштаб |
| Долгое нажатие | прицел с ценой и временем |
| Короткий тап (в чистом режиме) | старт / пауза |
| Свайп вниз по шапке настроек | закрыть панель |

## Настройки

### Инструмент
- **Тикер, диапазон цен** — коридор, внутри которого блуждает цена.
- **Стартовая цена** — на ней закончится история. Пусто — середина диапазона.
- **Макс. размер свечи** — ограничение хода одной свечи (High − Low). Например, `50` для BTC означает, что ни одна свеча не пройдёт больше 50 пунктов. Рядом показывается, сколько это в процентах от цены. Пусто — без ограничения. Ограничение действует и на историю, и на живое движение, и на путь к цели.
- **Волатильность** — множитель размаха.

### Движение к цели
Указываешь цену и число свечей. Последняя свеча закрывается **ровно** в целевой цене: шум по пути затухает к нулю. Направление считается само по знаку разницы.

Четыре характера движения: плавный тренд, с откатами, флэт-затем-импульс, сначала против-потом рывок.

Если задан максимальный размер свечи и цель за такое число свечей физически недостижима, движок скажет, сколько свечей нужно минимум.

### Позиция
- Маржа и плечо. PnL, ROE и цена ликвидации считаются как на бирже.
- **Тейк-профит** — цена, на которой позиция закроется сама. Когда цена его достигает, выскакивает окно с результатом сделки. Кнопки +20 / +50 / +100 % подставляют тейк по доходности от маржи в сторону открытой позиции.
- Ликвидация при пробое расчётной цены — тоже с окном.
- Линии входа, тейка и ликвидации рисуются на графике.

### Запись
- Скорость: от 0.2 до 8 секунд на свечу.
- Ширина свечи.
- Отсчёт 3 · 2 · 1 перед стартом.
- Кнопки Long / Short внизу экрана — можно убрать.
- Тикер бледным фоном — по умолчанию выключен, на видео его не видно.
- Чистый режим.

## Горячие клавиши (на компьютере)

| Клавиша | Действие |
|---|---|
| `Пробел` | старт / пауза |
| `B` / `S` / `C` | лонг / шорт / закрыть |
| `T` | задать цель |
| `H` | чистый режим |
| `V` | рамка 9:16 |
| `R` | новая история |
| `Esc` | закрыть окно или панель |

Колесо мыши — масштаб, перетаскивание — прокрутка, двойной клик — вернуться к последней свече.

## Как это считается

- **Диапазон** задаёт коридор, в котором цена блуждает случайно, упруго отбиваясь от границ.
- **Цель** — детерминированная траектория от текущей цены к заданной за N свечей плюс шум, амплитуда которого затухает к нулю к концу пути.
- **Максимальный размер свечи** зажимает цену внутри полосы `High − Low ≤ лимит` на каждом тике текущей свечи.
- **PnL:** объём = маржа × плечо, `PnL = (текущая − вход) × объём / вход`, ROE = PnL / маржа. Цена ликвидации упрощённая, `вход × (1 ∓ 1/плечо)`, без комиссий и ставки поддержания.

Данные полностью синтетические, к реальному рынку отношения не имеют.
