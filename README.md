# Chart Studio

График в стиле TradingView для записи роликов: свечи, таймфреймы, движение к заданной цене за заданное число свечей, позиция с живым PnL.

Обычный статический сайт — HTML, CSS и один файл JS. Без сборки, без зависимостей, без сервера.

---

## Деплой на Vercel через GitHub

1. Создай на GitHub пустой репозиторий, например `chart-studio`.
2. Распакуй архив и залей содержимое папки в репозиторий:

   ```bash
   cd chart-studio
   git init
   git add .
   git commit -m "Chart Studio"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/chart-studio.git
   git push -u origin main
   ```

   Либо просто перетащи файлы в веб-интерфейсе GitHub: **Add file → Upload files**.

3. Зайди на [vercel.com/new](https://vercel.com/new), выбери **Import Git Repository** и укажи этот репозиторий.
4. Framework Preset оставь **Other**, поля Build Command и Output Directory не заполняй — Vercel отдаст файлы как есть.
5. Нажми **Deploy**. Через минуту получишь ссылку вида `chart-studio.vercel.app`.

Дальше каждый `git push` в `main` обновляет сайт автоматически.

**Важно:** `index.html` должен лежать в корне репозитория, а не внутри вложенной папки.

Локально сайт открывается двойным кликом по `index.html` — можно проверить всё до деплоя.

## Как записывать ролик

1. Впиши тикер и диапазон цен, в котором ходит график. При необходимости задай стартовую цену — на ней остановится история.
2. Выбери таймфрейм сверху и скорость: «одна свеча за N секунд». Для динамичного тиктока подойдёт 0.3–1 с, для спокойного разбора — 2–4 с.
3. Задай цель: цену и за сколько свечей до неё дойти. Цена цели может быть выше или ниже текущей — направление считается само. Кнопки ±2/5/10% подставляют цену от текущей.
4. Выбери характер движения:
   - **Плавный тренд** — ровный ход в одну сторону;
   - **С откатами** — идёт к цели с коррекциями, самый правдоподобный;
   - **Флэт, затем импульс** — долго стоит, потом резкий вылет;
   - **Сначала против, потом рывок** — сначала выбивает в минус, затем разворот к цели.
5. Галочку «Показывать линию цели» лучше снять — иначе на видео будет видно, куда пойдёт цена.
6. Нажми **Чистый режим**, чтобы скрыть панель настроек, и **9:16** — если пишешь вертикальное видео.
7. Включай запись экрана и жми **Старт** (или пробел).
8. Открывай позицию кнопками **Long** / **Short** — на графике появится линия входа, а в правом верхнем углу карточка с PnL, ROE и ценой ликвидации. Всё пересчитывается на ходу.

Когда цена доходит до цели, график продолжает свободно ходить вокруг неё — запись можно не прерывать.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | старт / пауза |
| `B` | открыть Long |
| `S` | открыть Short |
| `C` | закрыть позицию |
| `T` | задать цель из полей панели |
| `H` | чистый режим |
| `V` | рамка 9:16 |
| `R` | новая история свечей |

Колесо мыши — масштаб, перетаскивание — прокрутка графика, двойной клик — вернуться к последней свече.

## Как это считается

- **Диапазон** задаёт коридор, в котором цена блуждает случайно, отбиваясь от границ. Волатильность — множитель к размеру шага.
- **Цель** — детерминированная траектория от текущей цены к заданной за N свечей плюс затухающий к нулю шум. За счёт затухания последняя свеча закрывается ровно в целевой цене.
- **PnL** считается как на бирже: объём позиции = маржа × плечо, `PnL = (текущая − вход) × объём / вход`, ROE = PnL / маржа. Цена ликвидации — упрощённая, `вход × (1 ∓ 1/плечо)`, без учёта комиссий и ставки поддержания.

Данные полностью синтетические, к реальному рынку никакого отношения не имеют.
